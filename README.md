(ระบบค้นหาหอพัก)



เว็บแอปพลิเคชันศูนย์กลางข้อมูลหอพัก ให้ผู้ใช้ค้นหาหอพักตามตำแหน่งบนแผนที่

OpenStreetMap แบบโต้ตอบได้ พัฒนาด้วย PHP, MySQL และ JavaScript



\*หมายเหตุ: ข้อมูลทั้งหมดเป็นข้อมูลจำลองเพื่อการทดสอบเท่านั้น\*



\## ฟีเจอร์

\- ค้นหาหอพักบนแผนที่

\- สมัครสมาชิก / เข้าสู่ระบบ / รีเซ็ตรหัสผ่าน

\- เจ้าของหอพักเพิ่ม แก้ไข และดูสถานะประกาศหอพัก

\- ผู้ดูแลระบบอนุมัติและจัดการประกาศ



\## วิธีติดตั้ง

1\. ติดตั้ง XAMPP แล้วคัดลอกโฟลเดอร์นี้ไปไว้ใน htdocs

2\. สร้างฐานข้อมูลใน phpMyAdmin

###### 3\. สร้างไฟล์ connect.php สำหรับเชื่อมต่อฐานข้อมูลของคุณเอง
